# Day Off Dough OS — แก้สูตรและวัตถุดิบ / น้ำและน้ำแข็ง

- วันที่: 2026-11-17 (Asia/Bangkok)
- สถานะ: ข้อเสนอสำหรับเจ้าของร้านตรวจและอนุมัติก่อนเขียนแผน implementation
- ฐานโค้ด: `main` ที่ `4d615f0`

## เป้าหมายและทางเลือก

เจ้าของร้านต้องการแก้และเอาสูตรหรือวัตถุดิบที่กรอกไว้แล้วออกจากรายการใช้งาน และยืนยันว่า **น้ำกับน้ำแข็งมีไว้บอกปริมาณที่ต้องเตรียมในสูตรเท่านั้น ไม่คิดต้นทุน ไม่นับและไม่ตัดสต๊อก**

- **แนวทางที่เสนอ:** แก้สูตรโดยใช้สูตรเดิมเป็นต้นแบบของเวอร์ชันใหม่ เก็บสูตร/วัตถุดิบที่เลิกใช้โดยไม่ลบข้อมูล และเก็บน้ำ/น้ำแข็งเป็นชนิดย่อยของวัตถุดิบที่แสดงในสูตรแต่ไม่เข้าสายงานต้นทุนและสต๊อก
- **ไม่ใช้การแก้ทับและลบถาวร:** สูตรและรายการเดิมถูกอ้างอิงโดยรอบผลิต ราคา และบัญชีสต๊อก การแก้ทับอาจเปลี่ยนความหมายของตัวเลขเก่า หรือทำให้รอบที่ล็อกแล้วไปต่อไม่ได้
- **ไม่ใช้วัตถุดิบปกติราคา 0 บาท:** แม้จะไม่เพิ่มต้นทุน แต่ยังถูกดึงไปนับสต๊อก ซื้อ หรือยืนยันยอดใช้ ไม่ตรงกับวิธีทำงานที่เจ้าของร้านเลือก

## พฤติกรรมที่เสนอ

### สูตร

- เริ่มแก้จากข้อมูลของเวอร์ชันที่เลือก: ผลผลิต ค่าแรง ค่าไฟ/แก๊ส ค่าเผื่อ วิธีทำ และรายการวัตถุดิบ เพิ่ม/ลบรายการหรือแก้จำนวนได้ ต้องเหลืออย่างน้อยหนึ่งรายการที่ถูกต้อง
- บันทึกด้วยรหัสเวอร์ชันใหม่ที่ไม่ซ้ำในสูตรเดียวกัน ไม่แก้เวอร์ชันต้นฉบับและไม่เปิดใช้แทนอัตโนมัติ เจ้าของเลือกเปิดเวอร์ชันใหม่เอง
- ใช้ **เก็บเข้าประวัติ** แทนการลบเวอร์ชันสูตร เวอร์ชันที่ใช้อยู่ต้องสลับไปใช้เวอร์ชันที่พร้อมก่อน เวอร์ชันเก็บแล้วอ่านประวัติได้ แต่ไม่เสนอให้เลือกเปิดใช้ตามปกติ รอบที่ล็อกแล้วยังใช้ชุดข้อมูลเดิม
- ขอบเขตนี้จัดการเวอร์ชันสูตร ไม่ลบรายการสินค้าหรือออเดอร์

### วัตถุดิบและบรรจุภัณฑ์

- แก้ชื่อ หน่วยซื้อ ปริมาณต่อแพ็ก สต๊อกขั้นต่ำ และหมายเหตุได้ ปริมาณต่อแพ็กใหม่เป็นค่าเริ่มต้นสำหรับรายการในอนาคต ไม่เขียนทับตัวเลขในประวัติราคา/ซื้อ/นับ
- อนุญาตให้แก้หน่วยฐาน ประเภท หรือชนิดย่อยเฉพาะรายการที่ยังไม่ถูกใช้ในสูตร กฎบรรจุภัณฑ์ ราคา สต๊อก หรือแผนผลิต หากเคยใช้แล้วให้สร้างรายการใหม่แทน ไม่แปลงหรือตีความปริมาณเก่าย้อนหลัง การมีแถว metadata สต๊อกที่ระบบสร้างไว้แต่ยังไม่เคลื่อนไหว ไม่นับเป็นการใช้งานเอง
- ใช้ **ปิดใช้งาน** แทนการลบถาวร รายการที่ปิดแล้วไม่อยู่ในตัวเลือกใหม่ แต่ยังเปิดดูประวัติได้ ตรวจและแจ้งสิ่งที่ต้องแก้ก่อนปิดเมื่อรายการยังอยู่ในสูตรที่เปิดใช้ กฎบรรจุภัณฑ์ที่ใช้ได้ หรือรอบที่ล็อกและยังไม่จบ ไม่ให้เปิดสูตรที่ต้องใช้วัตถุดิบที่ปิดแล้ว
- หน่วยซื้อและปริมาณต่อแพ็กถูกอ่านสดในบางขั้นตอนจัดซื้อ จึงยังไม่ให้เปลี่ยนสองค่านี้ระหว่างที่มีรอบที่ล็อกและยังไม่จบอ้างอิงรายการนั้น เพื่อไม่เปลี่ยนจำนวนแพ็กกลางรอบ

### น้ำและน้ำแข็ง: เฉพาะปริมาณเตรียมในสูตร

- คงประเภทหลักเป็นวัตถุดิบ เพิ่มชนิดย่อย **น้ำ** กับ **น้ำแข็ง** แยกจากวัตถุดิบทั่วไป โดยไม่เปลี่ยนความหมายของบรรจุภัณฑ์หรือวัสดุสิ้นเปลือง
- น้ำเลือกหน่วยฐาน `ml` หรือ `L` (รหัสเดิม `ml` / `l`), น้ำแข็งเลือก `g` หรือ `kg` ค่าเริ่มต้น `ml` และ `g` ตามลำดับ ไม่แปลงข้ามน้ำหนักกับปริมาตรอัตโนมัติ
- ใช้ปริมาณต่อสูตรเหมือนวัตถุดิบอื่น เช่น น้ำ 250 ml หรือน้ำแข็ง 100 g แต่ไม่ต้องกรอกราคา หน่วยซื้อ หรือยอดสต๊อก ไม่เรียกต้นทุนว่า “ยังไม่มีราคา” และไม่สร้างราคา 0 บาทปลอม
- ในแผนใหม่ไม่สร้างรายการต้นทุนหรือสต๊อกจากวัตถุดิบชนิดนี้ ไม่เข้ารายการซื้อ การตรวจนับ หรือบันทึกใช้จริง ไม่เพิ่มคำเตือนราคาขาด และไม่หักสต๊อก โดยยังคงต้นทุนแรงงาน ค่าไฟ/แก๊ส และวัตถุดิบอื่นตามเดิม
- แสดงปริมาณ **เฉพาะในสูตร** ไม่เพิ่มรายการเตรียมแยกตามจำนวนแบตช์หรือหน้าจัดซื้อในงานนี้ รอบที่มีเฉพาะรายการเตรียม (และไม่มีบรรจุภัณฑ์ที่ต้องนับ) ต้องไม่มีรายการให้ตรวจนับปลอม และเริ่มผลิตได้ตามเงื่อนไขอื่นเดิม

## ข้อกำหนดการส่งมอบ

- รายการและเวอร์ชันที่มีอยู่คงสถานะเดิม ไม่เดาชนิดจากชื่อรายการและไม่แก้สูตร ราคาหรือยอดร้านย้อนหลัง ใช้การเปลี่ยนแปลงกับแผนที่สร้างใหม่เท่านั้น ห้าม migration แก้ประวัติของรอบที่ล็อกแล้ว
- เปิดใช้การเปลี่ยนแปลงด้วยการตรวจสิทธิ์เจ้าของร้านและตรวจเงื่อนไขฝั่งเซิร์ฟเวอร์ ไม่พึ่งการซ่อนปุ่มเพียงอย่างเดียว ป้องกันแข่งกันระหว่างการเปิดสูตร ปิดวัตถุดิบ บันทึกราคา/นับ และล็อกแผน
- ตรวจทั้งกรณีสูตรผสม (อย่างเช่น แป้ง + น้ำ + น้ำแข็ง) และกรณีไม่มีวัตถุดิบที่ต้องนับ รวมถึงวัตถุดิบปกติที่ไม่มีราคายังเตือนตามเดิม เวอร์ชันเดิมอ่านได้ และรอบที่ล็อกก่อนเปิดฟีเจอร์มีต้นทุน/ยอดเดิม
- งานนี้แบ่งเป็นสามส่วนที่เกี่ยวข้องกัน: ดูแลเวอร์ชันสูตร, ดูแลรายการวัตถุดิบ, และรองรับน้ำ/น้ำแข็งในสูตร รวมการทดสอบ migration และ workflow บนฐานทดสอบ ไม่รวมการ push, deploy หรือรัน migration บน Supabase ร้านจริงโดยอัตโนมัติ
